# 🏦 Banking Relationship Manager Analytics

### Data Analytics Project | Banking Domain

> **Turning raw and inconsistent banking data into structured, business-ready insights using Python and SQL.**

---

## 📌 Project Overview

This project focuses on analyzing **Relationship Manager (RM) performance and customer-related banking data** to understand sales activity, target achievement, customer information, loan portfolios, complaints, and customer feedback.

The project follows an end-to-end **Data Analytics workflow**, starting from synthetic dataset generation and raw data creation, followed by data cleaning using Python, database storage in MySQL, and SQL-based business analysis.

> **Note:** The dataset used in this project is synthetically generated using Python because real banking/RM data is not publicly available for portfolio development.

---

## 🎯 Business Objective

The main objective of this project is to analyze banking data and generate insights around:

- 👨‍💼 Relationship Manager performance
- 💰 Sales and revenue activity
- 🎯 Target and achievement
- 👥 Customer information and segmentation
- 🏦 Loan portfolio
- 📞 Customer complaints
- ⭐ Customer feedback and ratings
- 🏢 Branch and RM-level performance

The project demonstrates how raw operational data can be transformed into structured information for **data-driven business analysis**.
